# Qualification boundaries

`npm ci`, `npm run lint`, `npm run test:coverage`, `npm audit --audit-level=low`, `npm run build` and `CHROME_PATH=... npm run test:browser` qualify the local source. Coverage thresholds are 80% statements/functions/lines and 70% branches for the selected core parsers, RPC and operation/reconciliation code. State ownership and fixture orchestration have separate deterministic regressions; dialog behavior is qualified in Chromium. Coverage is not a security proof and the reported percentage is not whole-application coverage.

The browser suite uses the actual Vue components with offline provider/RPC fixtures and blocks outbound requests. It tests five views in both themes at 320/375/768/1024/1440 pixels with connected and disconnected wallets, invalid recipients/amounts, unknown health, original late results, queued economic changes, reverted receipts, actual cross-tab ownership, redirect policy and nested dialog keyboard/focus behavior. Pool/stake fixtures cover identity, approval/revert, LP postconditions, zero/halted/unavailable programs, pagination, expiry and submitted-only status. Browser and result artifacts are recorded. It does not qualify a real extension, actual DEX/LP minting, economic reward cycle or complete LP bridge lifecycle.

The isolated lab asserts loopback endpoints and Zenon/EVM chain IDs 322/31337 before fixture writes. `e2e/lab/pins.json` pins the source commit/tree, Go, base images, Anvil version/archive digests and browser version. Build manifests bind the committed Git export and every overlay input. Solidity cache keys bind compiler version, settings, direct sources and the complete installed OpenZeppelin Solidity tree. Runtime manifests record executable, genesis and config hashes. Native readiness requires five nodes to agree on recent momentum hashes; mere height movement is insufficient.

The one-key fixture orchestrator verifies canonical EVM log identities, uses bounded paginated unsigned history, and marks a job complete only after publication. Failed reads remain failures. Known registered entries are checked by exact transaction hash/log index. Native nodes use the pinned source's libp2p transport with explicit capacity. Before signing, publications wait for depth three and a receive source's confirmation. Protocol delay boundaries use controlled EVM mining; UI waits use interval mining. The lab journal retains an unknown signed block and refuses a replacement; a short reorg can therefore correctly fail a qualification run. Archive that run's evidence and use a fresh isolated test state rather than changing the original signed operation. Deep reorgs, distributed TSS and production recovery remain external gates.

`Qualification` CI runs integrity checks on supported Node majors and a pinned native lab/browser job without a skip fallback. A workflow file or local pass is not a hosted result. `Pages` has deployment rights only in its final job. Maintainer approval, clean-platform wallet tests, distribution provenance and [production gates](DEPLOY.md) remain separate.

The interface intentionally pauses new transfers on stale/unknown safety data and new stakes while rewards are zero. Review these product policies before production activation. Submitted transactions and source confirmations do not imply that the opposite bridge side completed.
