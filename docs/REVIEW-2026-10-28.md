# Review, 2026-10-28

An adversarial pass over the whole front end, then the owner's taste review
(z-sol) over the interface. Every finding below was fixed in the working tree
unless it says otherwise. Nothing is committed.

Findings are ranked by who can reach them: a stranger's website first, then a
service the page talks to, then the user's own browser, then everyone who uses
the page as written.

## Security and correctness

| # | Who reaches it | Finding | Fix |
|---|---|---|---|
| 1 | Any website | The page ran inside any site's frame. GitHub Pages sends no `frame-ancestors`, and a meta CSP cannot carry it, so a hostile page could overlay the bridge and steer clicks into a wallet prompt. | `src/main.ts` checks before the app loads. Framed by another origin, the page renders only a link that opens it in its own tab. A same-origin frame still works. |
| 2 | Plasma bot | A failed or successful plasma request put the bot's own response text in a toast. A third party chose words shown inside the bridge. | The toast says ours: "Plasma requested" or "Plasma bot busy. Try later." |
| 3 | Plasma bot | After a failed request the page opened zenonhub with `window.open` after an `await`, which popup blockers swallow without a word. | The form opens on the click only when there is no token. After a failure, the toast carries a zenonhub link. |
| 4 | Any image host | The CSP allowed `img-src https:`. Nothing needs it: EIP-6963 wallet icons are data URIs by the standard. A broad image source is an exfiltration path for any future injection. | `img-src 'self' data:`. Wallet icons still render. |
| 5 | The user's browser | An unreadable operation journal paused every send forever. The only way out was clearing site data, which also destroys the evidence the pause exists to keep. | When, and only when, the stored journal fails validation, Activity offers **Download and reset**. The raw journal is saved to a file first, then the key is removed. A journal that reads is never offered this. |
| 6 | The user's browser | Watch accepted a mis-cased `0x` address. The form passed it, the store dropped it, nothing said so. | The form uses the store's own test and says "Not an address". |
| 7 | Every swap | A quote expired and was never fetched again. The "Quote expired" blocker could not appear either: `Date.now()` is not reactive. The send guard caught it, so a stale quote never went out, but the user met a failed send instead of a fresh quote. | The next quote is fetched ten seconds before expiry, and not while a send is open. |
| 8 | Every native-coin swap | Max kept back a fixed 0.005 of the native coin on both chains: too little on Ethereum in a gas spike, many times too much on BNB Chain. | The reserve is the live gas price times 400,000 gas, doubled. A failed read falls back to 0.005. |
| 9 | Every user | Activity printed the raw library message on a failed read, and its note rendered a double period. | "History unavailable", or "History changed while reading. Refresh." |
| 10 | Every user | The wallet mismatch message ran past 80 characters and was truncated mid-word in the toast. | "Wallet signed different details." |

Seen and left as they are, with the reason:

- **Swap calldata is opaque.** The page checks the router and spender
  addresses against the configured ones, not the recipient inside the
  calldata. This is the documented trust assumption in
  [SUPPORT](SUPPORT.md); decoding three routers' calldata is its own project.
- **Switch network adds the chain** to the wallet with the build's public RPC
  when the wallet does not know it. The wallet shows that RPC before adding it.
- **The plasma bot token ships in the bundle.** That is the owner's decision,
  recorded in [DEPLOY](DEPLOY.md); a token-holding proxy is the alternative.
- **A referral is first-wins.** A later link does not replace the stored one
  until the user presses Clear on the banner.
- **Web Locks and `crypto.randomUUID` need a secure context.** Over plain HTTP
  the page refuses to sign and says why.
- **The reset in finding 5 lifts the block** on whatever the unreadable journal
  held. The download is the record; RECOVERY says to keep it and check the
  wallet's history before sending the same thing again.
- **A `frame-ancestors` header** is still the stronger control than the
  script check in finding 1. GitHub Pages cannot send one; the CDN in front of
  the domain can, with a response-header rule.

## The owner's taste review

The z-sol agent read the page as the owner would. What it would send back, and
what was done:

| It would insist on | Done |
|---|---|
| One down state, one word, one place. The banner said "{network} bridge is down", the form added a health note, the switch said "Send while the bridge is down". | The banner reads "**Bridge is stalled.** Swaps still work." The action button says "Bridge is stalled". The form note is gone. The switch is "Send anyway". Halted and new-key states follow the same shape. |
| No "0.00", no "Balance 0" before a wallet connects, no dimmed fractions. | Placeholders are "0". An unread balance is a dash. Fractions render at full weight. |
| Journal words and raw states out of the interface, and the recovery panel on one page. | The panel is "Unconfirmed", on Activity only. States read In wallet, No reply, Sent, Differs. Every message about it was rewritten without "journal", "publication" or "operation". |

| It would wave through | Kept |
|---|---|
| The form shape, the Bridge and Swap toggle, Advanced, the Details row, the starfield | Yes |
| The icon-only dock | Yes, four wide now |
| Approve as its own press | Yes |

Also applied from the same review:

- **Status, not Stats.** The tab and heading say Status.
- **Referral moved** from the tab bar to the More menu. The dock and header
  carry four sections.
- **Status page.**
  - Times are relative, with the exact time in the tooltip.
  - Delays read as durations, with the momentum and block counts in the tooltip.
  - "Running" and "Unknown" replace "Not halted" and "Unread".
  - Route open or closed shows a mark, not colour alone.
  - Configuration and Liquidity program are folded by default.
  - The hedged sentences are cut to one line each.
  - Every figure that was on the page is still on it.
- **Tables stack at phone width.** Each row becomes a labelled card, so
  nothing scrolls sideways and nothing is dropped.
- **Toasts.** One at a time, 2.5 s, 4 s for an error, with a bar that drains.
  Texts are two or three words: "Wrap sent", "Approval sent", "Swap
  confirmed", "Stake sent".
- **Terms.** One checkbox under the six terms instead of six.
- **Blockers.** "Invalid amount", "Quote expired", "Balance unavailable",
  "Check Activity first".
- **Steps.** "Send, then 2 redeems on Ethereum".
- **Plasma.** "No plasma. Sending will be slow." and "Recipient needs plasma
  to redeem." The button always says "Get plasma".
- **Glass.** Cards and menus catch a faint light from above in the dark
  theme, menus and toasts are glass, the header mark has a soft glow.
- **Docs.** The readme lost its dated stall sentence and gained credits.
  SECURITY and SUPPORT are shorter. RECOVERY is steps, a state table and one
  sequence diagram. FUNCTIONALITY lost its second paragraph.

Not done: a custom node URL in the wallet menu. It was offered as optional
and touches node validation, which deserves its own change.
